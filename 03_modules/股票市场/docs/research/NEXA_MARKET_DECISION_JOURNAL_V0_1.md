# Decision Journal V0.1

Decision Journal 记录“当时为什么这样想”，不是交易日志。

- 包含 thesis、attention reason、assumptions、支持/反方 evidence、uncertainty、invalidation 和 expected observations。
- 状态：`ACTIVE / INVALIDATED / CLOSED / REVIEWED / ARCHIVED`。
- Outcome/Retrospective 记录实际发生事项、失败假设、变化证据、遗漏、经验与复盘后 confidence。
- 已记录内容不可 replace；观点变化或复盘创建新 revision，并以 `supersedes` 保留 lineage。
- 合同不含可执行交易动作。
